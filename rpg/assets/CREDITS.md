# CC0 world assets

Everything here is CC0 1.0 (public domain). No attribution is required; credits are listed anyway. Downloaded 2026-10-07.

- `textures/1k/`: original 1024px JPGs: `<name>_diff` (colour), `<name>_nor_gl` (OpenGL normal, works with three.js as is), `<name>_rough`.
- `textures/512/`: the same maps resized to 512px at JPEG q78 (~4 MB total), meant for inlining into the single HTML file.
- `models/<kit>/`: low-poly GLB models. castle, graveyard and survival GLBs reference `Textures/colormap.png` next to them (keep that path or embed it); nature GLBs use plain colour materials and need no texture. `_preview.png` shows each kit.

- models/graveyard: Graveyard Kit, https://kenney.nl/assets/graveyard-kit (crypts, gravestones, crosses, iron fences, pillars, altars, dead pines)
