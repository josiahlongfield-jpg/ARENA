# Sound credits: templar-arena/sounds-cc0

Every file here is **CC0 1.0 (public domain)**, so no attribution is required. Crediting is still polite.
All files are mono MP3, 44.1 kHz, 112 kbps. They were trimmed of leading and trailing silence and given a short fade-out.
Licences were checked against the licence file shipped with each pack, and for the Freesound originals against the Freesound page itself (October 2026).

Kenney packs were fetched from the GitHub mirror `series-ai/jam-ready-assets`. Each pack's `License.txt` there states CC0.
The other files were fetched from the CDDA "CC-Sounds" soundpack (github.com/Fris0uman/CDDA-Soundpacks), which lists the original author and link for each file in a `credits.md`.

## Warhammer 40k bolter / bolt pistol sounds
No openly licensed (CC0 or CC-BY) bolter or bolt pistol recording was found.
- Freesound and OpenGameArt searches turned up nothing tagged bolter or bolt pistol under a free licence.
- archive.org "Boltersinglefire" (uploaded by Razorfiend, 2021) has no licence and is almost certainly ripped game audio. Do not use it.
- The Nexus Mods and Steam Workshop "bolter" mods reuse Games Workshop or licensed game audio (Darktide, Space Marine 2). Do not use them.

The bolt sounds above are generic CC0 gunshot and explosion recordings chosen to suggest a bolt round.
